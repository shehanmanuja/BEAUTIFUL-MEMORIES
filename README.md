# Our Beautiful Memories — Dark Purple Romantic Theme 💜

A personal, romantic memory website dedicated to your girlfriend with a **luxurious Dark Purple & Neon Violet aesthetic**, specially optimized for viewing on mobile phones.

---

## 💜 How to Add Photos & Videos

All your files now stay directly inside the **`MEMORIES`** folder (no subfolders needed!).

### 1. How to Add Photos or Videos
1. Copy your photos (`.jpg`, `.png`, `.jpeg`) or videos (`.mp4`, `.mov`, `.webm`) directly into this **`MEMORIES`** folder.
2. Open [script.js](file:///c:/Users/SHEHAN_EPE/Downloads/MEMORIES/script.js) and scroll to `GALLERY_IMAGES` near the top:
   ```javascript
   const GALLERY_IMAGES = [
     // Photos:
     { src: "IMG_0360.jpg", caption: "A Sweet Moment Together" },

     // Videos:
     { src: "our-video.mp4", caption: "Our laugh together" },
     { src: "trip-clip.mov", caption: "Our memorable trip" },
   ];
   ```
3. Videos will automatically display:
   - A glowing **Video badge** in the memory grid.
   - Hover preview on desktop / tap to open on mobile.
   - Full high-definition video player in the Lightbox with play/pause and volume controls.
   - Background music automatically pauses when your memory video plays so the audio doesn't clash!
